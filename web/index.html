      How Room reads a script

      1. Read. Gemini finds every reference and names the job it does in the line. Drop a PDF, a deck or a document and Room reads that too.
      2. Match. Qloo search turns each one into an entity in its taste graph.
      3. Score. Known is how much of a city recognises the reference: Gemini's estimate, raised wherever Qloo measures a real local fan base. Loved is Qloo's median affinity in that city, read for the age band you pick.
      4. Review. For any city, an agent decides what to swap, what to drop and what to keep. Qloo finds local swaps and tests each one. You accept or ignore every suggestion, like a spellchecker for culture.
      5. Tour. Give Room up to eight stops and it reviews the set for each one, then prints a set list per city.
      6. Picture. Drop a frame or a clip from an ad and name the brand. Gemini reads what is on the TV, in hand and on the wall. Qloo scores each element for the brand: how its fans lean against the average brand fan, who holds it in Qloo's brand records, and how each city feels about it. Room redraws a flagged element in place and reads the new frame back.
